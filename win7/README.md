# 浮岛 Win7 专版

这是单独维护的原生 Windows 7 版本，面向 32 位和 64 位 Windows 7。应用和安装器均为 Win32 C++ 程序，不需要安装 .NET Framework、Visual C++ Redistributable、Node.js 或浏览器。运行时仅使用 Windows 系统 DLL；C++ 支持库静态链接。

运行 `dist/FreeIsland-Win7-Setup-1.0.6.exe`，输入安装目录或点击「浏览」选择，再确认开机静默启动、桌面快捷方式并点击「安装浮岛」。安装完成后点击「打开浮岛」，或从开始菜单打开「浮岛 Win7」。默认目录通常无需管理员权限；自选目录需要当前账户具有写入权限。

默认使用课堂场景，并保留更紧凑的电脑场景。提供悬浮球、环形入口、可拖动和靠边收起的灵动岛、正计时、倒计时、全屏展示、日程提醒、可取消的预约关机、托盘及本地设置。Windows 7 版使用原生窗口与 GDI+ 重建界面，与原 WPF 版本分别构建。

默认安装目录：`%LOCALAPPDATA%\Programs\FreeIslandWin7`，升级会沿用已注册的安装目录。选择新目录时，旧程序文件会保留，同一版本共用设置与日程目录 `%APPDATA%\FreeIslandWin7`；请使用空文件夹或有效的浮岛安装文件夹。两个版本的安装与数据目录相互独立。启动项位于当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，名称为 `FreeIslandWin7`，指向带引号的应用路径及 `--silent` 参数。卸载器根据自身安装位置卸载，不再依赖固定的默认目录。

可从 Windows 7「控制面板 → 程序和功能」卸载，也可双击安装目录中的 `FreeIslandWin7.Uninstall.exe`。卸载器请求浮岛正常退出，不强制终止进程，只删除已知安装文件和属于该安装的快捷方式、注册表项；不递归删除目录。本地设置和日程默认保留。为删除正在运行的卸载器，它会复制到系统临时目录完成操作；该临时文件可通过 Windows 临时文件清理移除。

安装包内嵌应用及其 SHA-256 值，提取前使用 Windows CryptoAPI 验证。仅验证并提取、不安装的命令：

```powershell
.\dist\FreeIsland-Win7-Setup-1.0.6.exe --verify-payload "D:\free island\artifacts\win7-payload-check"
```

该命令只向指定目录提取应用与运行库许可文件，不会启动应用、创建快捷方式、写入启动项或修改正式数据。安装包的内嵌哈希用于发现损坏，不替代发布者数字签名。

从仓库根目录构建：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\win7\build-native.ps1
```

构建使用 i686 MinGW-w64 / MSVCRT 工具链，生成 x86 PE，目标系统版本为 Windows 7。构建脚本和工具链仅供开发使用，最终用户只需运行安装包或便携应用。具体输出文件、导入 DLL 和校验值以构建结果为准。

当前尚未在实体 Windows 7 电脑或实体教学触摸大屏上完成验证。现代 Windows 上的构建、运行及安全模式检查，不能代替 Windows 7 真机、不同显卡或触摸驱动的兼容性测试。开发测试不会执行真实关机，也不会实际安装或更改操作系统启动设置。正式使用时，预约关机不会强制关闭其他应用。

## v1.0.6 · 2026-09-17 更新

正计时与倒计时同时进行时，收起的灵动岛显示时间缩略球及数字 `2` 角标，暂停中的计时也计入。点击缩略球展开独立的任务卡片，各自提供操作；收起球和卡片主体继续支持拖动。倒计时细环表示剩余比例，正计时细环表示一分钟内的秒数。当前支持一项正计时与一项倒计时同时运行，没有增加任意多项独立倒计时。

有任务时缩略球显示为 30–50 物理像素，默认教室 48、电脑 36。在「设置 → 任务球大小」中分别调整并保存两个场景的大小，也可恢复当前场景默认值；任务结束后恢复原有 3–20 像素小点。它沿用玻璃外观设置和触控交互区域。打开环形功能菜单的原悬浮球保持原有用途。

教室模式使用触屏滑块选择倒计时的小时、分钟和秒，配有加减微调；选择时长后点击开始才启动。提醒和关机点击日期时间按钮进入选择面板，用前一天/后一天、小时/分钟滑块及加减按钮选择，点完成返回；电脑场景保留键盘输入。提醒提供「课间休息 / 准备上课 / 放学提醒」内容快捷项。定时关机只有最后 10 秒才占用灵动岛，此前在后台低频等待，可随时从控制中心或托盘取消。

本版继续使用原生 Win32 / GDI+，无需 .NET，且不采样或折射真实桌面。当前构建与安全测试结果以 [验证记录](../VERIFICATION.md) 为准；未在实体 Windows 7 或教室触摸硬件上验证。

## v1.0.5 · 2026-09-16 更新

在「设置 → 调整玻璃外观」中新增「曲面厚度 / 透明度 / 高光强度」三个 0–100% 滑杆，推荐值依次为 50%、65%、55%。拖动时即时预览，松手后保存；可一键恢复推荐参数。旧设置会补入推荐值并保留原有玻璃模式。这里的「曲面厚度」调节曲面材质的外观，不会读取或折射真实桌面。

参数同步用于悬浮球、灵动岛主体和收起的小水滴；透明度调节不改变文字衬底的透明度，便于继续读清任务内容。关闭玻璃时使用纯色材质，参数保留以便重新开启后继续使用。

灵动岛收起点跟随「关闭 / 轻量 / 水滴动效」材质设置：关闭时为黑点，玻璃开启时为透明小水滴，无需单独开关。默认大小仍为 20%（约 6 像素），设置中通过 0%–100% 滑杆调整为 3–20 像素；展开比例仍为 75%–150%。收起点保留点击恢复、拖动和靠边吸附，透明交互区域仍为电脑 24 × 24、教室 44 × 44 逻辑像素。

展开灵动岛的标题和详情字号略微增大，并增加局部半透明文字衬底，帮助在深浅或复杂背景上阅读；四周保留清透水滴材质。Win7 版不提供真实桌面折射。六个功能按钮仍独立排列，菜单没有大圆底板。

父窗口按内容变化重绘，计时按可见秒数变化更新，保留此前的原生控件防覆盖处理。当前验证结果见 [验证记录](../VERIFICATION.md)，仍需在实际 Win7 显卡和教室大屏上确认效果。

在「设置」选择「关闭 / 轻量 / 水滴动效」，默认轻量并保留已有选择。轻量提供清透表面和细边缘，无持续动画；水滴动效在按压、拖动时柔和形变，文字保持原位，松手后回弹。Win7 版不采样桌面，也不提供真实背景折射。WPF 版在 v1.0.5 中为初代 Windows 10 新增了兼容背景采样，并将最低运行环境降到初代 Windows 10 自带的 .NET Framework 4.6；这是单独构建的 Windows 10/11 版本，不改变 Win7 版免 .NET 的运行要求。收起的小水滴不循环闪烁或呼吸，六个功能按钮之间保持透明间隔。

覆盖安装会请求旧程序正常退出，暂存并校验新文件后替换；文件短暂占用时重试，替换失败则回滚。升级保留设置、日程以及已有的自启动和桌面快捷方式选择。两种版本分别升级各自的安装目录。
