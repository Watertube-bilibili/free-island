# 历史版本备份

这里保存在 v1.0.7 开发前留存的旧版工程源码压缩包、安装器、便携包、独立卸载器和校验文件。文件保留原名；未带版本号的历史文件不推测具体版本。

`manifest.json` 记录每个文件的大小、SHA-256 和 Git blob SHA。旧包上传到 GitHub `main/backup` 并逐项核对后，清理本地 `dist` 中对应的旧包。当前工程源码和最新安装包保留。

下载使用请优先选择仓库的 [最新 Release](https://github.com/Watertube-bilibili/free-island/releases/latest)。这里的旧安装包仅供历史留档和问题回溯，不代表当前推荐版本。

本地工程只保留本目录的说明及清单；完整历史文件保存在 GitHub。
