# 浮岛 · FREE ISLAND

一个面向教室大屏和个人电脑的 Windows 时间助手：悬浮球负责随时呼出功能，灵动岛在计时变化、提醒到达时按需出现。课堂场景优先支持触摸，也支持鼠标操作。

## Windows 7 原生版

Win7 专版的应用和安装器使用原生 Win32 C++ / GDI+，支持 32 位和 64 位 Windows 7，不需要 .NET Framework 或 Visual C++ Redistributable。

- 安装包：`dist/FreeIsland-Win7-Setup-1.0.8.exe`
- 免安装包：`dist/FreeIsland-Win7-Portable-1.0.8.zip`
- [Win7 使用与卸载说明](win7/README.md)、[构建工具链说明](tools/TOOLCHAIN.md)；校验值在 `dist/SHA256SUMS-Win7.txt`。
- 已公开发布的版本见 [GitHub Releases](https://github.com/Watertube-bilibili/free-island/releases)。本地构建版本以安装包文件名为准。

默认安装目录为 `%LOCALAPPDATA%\Programs\FreeIslandWin7`，可在安装窗口输入路径或点「浏览」选择。升级会记住上次目录。本地数据为 `%APPDATA%\FreeIslandWin7`，与下面的 WPF 版分别保存。Win7 原生源码位于 `win7/src/`；从仓库根目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\win7\build-native.ps1` 构建。

构建包含原生核心测试、PE 依赖检查与安全模式界面验证；具体结果见 [验证记录](VERIFICATION.md)。这些验证不涉及真实关机、安装或开机启动设置。目前未在实体 Windows 7 电脑或教学触摸大屏上测试。

## Windows 10 / 11 WPF 版：安装与运行

1. 运行 `dist/FreeIsland-Setup-1.0.8.exe`，输入安装位置或点「浏览」选择文件夹，然后点击「安装浮岛」。
2. 默认勾选「开机静默启动」和「创建桌面快捷方式」，可以按需取消。
3. 安装后从桌面或开始菜单打开「浮岛」。管理员重试完成后点击「完成」，再从桌面或开始菜单启动应用。

安装记录仅作用于当前 Windows 用户。默认目录为 `%LOCALAPPDATA%\Programs\FreeIsland`，通常无需管理员权限。自选受保护目录时可能需要权限；访问被拒绝后，可点击「管理员重试」，经 Windows 授权后重新确认安装。开机启动是用户登录后的静默启动：显示悬浮球与系统托盘图标，不弹出控制中心，灵动岛收起为屏幕边缘的小点（关闭玻璃时为黑点，开启时为透明水滴）。

升级默认沿用已有目录。改到新目录安装时，旧目录文件会保留，同一版本的设置和日程继续共用；当前账户的浮岛快捷方式和自启动项按所选选项更新。请选择空文件夹或原浮岛安装文件夹。卸载窗口会显示要移除的路径，默认保留本地设置。

免安装版为 `dist/FreeIsland-Portable-1.0.8.zip`。解压到固定目录后运行 `FreeIsland.exe`。如开启开机启动，请勿移动或删除该目录；移动后可在新位置重新关闭并开启自启动。

运行环境：Windows 10 1507（Build 10240）及以后版本 / Windows 11，.NET Framework 4.6 或更新版本。初代 Windows 10 已自带 .NET Framework 4.6，无需为本版升级至 4.8；精简系统若移除了该组件，需要先修复运行环境。应用与安装器未进行商业代码签名，Windows 可能显示「未知发布者」提示。发行文件的 SHA-256 校验值见 `dist/SHA256SUMS.txt`。

## v1.0.8 · 本地助手与自定义音频（2026-09-24）

标准版新增可选 llama.cpp 本地模型，一键下载并启用真实的 Qwen3 0.6B / 1.7B / 4B 三档，不内置模型。读取前台应用名称，生成可点击的音量、媒体控制、计时和日程快捷操作。基础场景推荐无需模型，默认关闭；Win7 版支持本地规则快捷和音量滑块。

倒计时、日程、关机最后 10 秒支持分别选择 WAV / MP3、试听、音量与恢复默认。模型功能限定 Win10 2004+ 的 x64 / AVX2 设备；早期 Win10 与 Win7 保留基础功能和轻量推荐。完整说明、下载体积、隐私边界和许可见 [本地助手说明](LOCAL_AI.md)。

## v1.0.7 · 星期循环关机、任务球与自动更新（2026-09-17）

定时关机增加闹钟式重复计划：可选择「每天」「工作日」或单独勾选星期一至星期日，例如只选 1、2、3、4、5。设置一个时、分，点击启用后按所选星期循环执行；修改选项不会直接预约。计划保存在本机，浮岛重新启动后恢复下一次未来时间。关闭计划会停止所有后续重复；仍只在最后 10 秒显示灵动岛预警。电脑未运行、休眠错过或预警不完整时，跳过本次，等待下一个所选日期，不补关机。循环计划需要浮岛在后台运行。

任务缩略球默认放大为电脑 64、教室 88 物理像素，支持 40–160 像素调节。首次升级时将旧版偏小的 30–50 像素设置迁移到新默认值，之后保留个人调整。空闲小点仍使用原有 20% 默认设置。

设置中新增 GitHub 自动更新开关、立即检查和状态反馈。默认启动后约 30 秒检查，之后每 6 小时检查一次；只接受本仓库正式 Release 中版本更高、对应本版的安装器。下载使用 HTTPS，并验证文件大小和 SHA-256；失败保留现有程序，可以手动重试。

安装版下载就绪后，等控制中心及全屏展示关闭、正计时/倒计时（包括暂停任务）结束、单次关机预约取消或完成，再自动安装并静默重启。已保存的循环关机计划允许在距离下次关机超过 5 分钟时更新，更新重启后恢复计划。沿用原安装目录、开机启动及快捷方式选择。自动升级不提权；权限不足会显示失败状态，需手动运行安装器。失败版本不会在后台反复安装重启。便携版可检查和下载安装器，需要手动决定是否安装。

更新需要连接 GitHub；基础计时和提醒仍离线运行。较旧 Win7 若缺少 TLS 1.2 或有效系统证书，检查会失败并显示状态，不降低连接安全要求。v1.0.6 及更早版本没有自动更新功能，需手动安装一次 v1.0.7，此后可自动接收新版。

旧版工程与发行文件已归档至 [main/backup](https://github.com/Watertube-bilibili/free-island/tree/main/backup)，附文件大小与哈希清单。备份验证后清理本地对应旧包，保留当前源码和最新安装包。

## v1.0.6（2026-09-17）

灵动岛收起点现在会显示正在进行的任务：中间是计时时间，外围细环显示倒计时剩余比例；正计时使用每分钟循环的秒数指示环。正计时和倒计时可以同时运行，暂停中的任务也保留。两者同时收起时，右上角显示数字 `2`；点击后同时展开两张独立任务卡片，可分别暂停、继续或结束。展开卡片和缩略球都能拖动，玻璃材质继续跟随原有设置。原来打开六个功能选项的悬浮球保持原有用途。

有计时任务时，收起点自动变成 30–50 物理像素的缩略球，默认教室 48、电脑 36。WPF 版在「设置」中自定义直径或选择跟随场景；Win7 版在「设置 → 任务球大小」中分别保存两个场景的大小，也可恢复当前场景默认值。任务全部结束后恢复原有小点尺寸，默认滑杆 20%（约 6 像素）。触屏交互区域仍有至少 44 × 44 逻辑像素，不随可见小点一起缩小。

教室模式自定义倒计时改成小时、分钟、秒滑块，配有加减微调和常用时长。选择时长后再点「开始倒计时」，滑动与快捷选择都不会直接启动；电脑模式保留输入框。提醒与关机时间也提供触屏日期、小时和分钟选择，提醒内容提供常用文字快捷项，减少键盘输入。WPF 使用日历及今天/明天快捷选择；Win7 点击日期时间进入独立面板，用前一天/后一天和时分滑块选择，点完成返回。

预约关机在最后 10 秒才显示灵动岛，此前不占计时缩略球或任务数量角标，空闲等待时降低检查频率。仍可在控制中心、托盘或最后的关机卡片取消。休眠后错过或未完成预警的计划继续取消，不会唤醒后突然关机。本版同时支持一项正计时和一项倒计时，并不支持创建任意多项独立倒计时。

## v1.0.5（2026-09-16）

水滴模式新增早期 Windows 10 兼容采样，面向初代 1507 和学校常见的 17xx 系统。应用及安装器最低运行环境降为 .NET Framework 4.6，并使用对应参考程序集编译，避免误用较新版本的接口。兼容路径的开发测试范围见 [验证记录](VERIFICATION.md)，尚未在实体 Windows 10 1507 或学校大屏上验证。

新增折射度、透明度、边缘高光三个 0–100% 调节项，推荐值依次为 50%、65%、55%。调整会即时预览并自动保存，也可一键恢复推荐值。Win7 版对应选项为「曲面厚度 / 透明度 / 高光强度」，其中曲面厚度调节材质外观，不代表真实背景折射。透明度调节不改变灵动岛文字衬底的透明度。

收起的小点继续跟随同一组「液态玻璃」设置：选择「关闭」时保持黑点，选择「轻量」或「水滴」（Win7 为「水滴动效」）时显示透明小水滴。无需单独开关，原有材质选择和默认轻量模式保留。两版仍可点击恢复灵动岛、拖动位置并在松手后靠边吸附。

灵动岛主体的标题和详情字号略微增大，并增加局部半透明文字衬底，帮助在深色、浅色和复杂背景上阅读；四周保留水滴材质，现代 Windows 水滴模式保留边缘折射。Win7 版仍不提供真实桌面折射。当前验证范围与结果见 [验证记录](VERIFICATION.md)。

## 水滴材质与尺寸设置

在「设置 → 液态玻璃」选择「水滴」，WPF 版会尝试折射浮窗下方的真实画面，并在按压和拖动时柔和形变；文字与图标保持原位。原有选择会保留，默认仍为「轻量」。根据系统版本自动选择背景采样方式：

- **初代 Win10 至 2004 之前（Build 10240–19040）**：异步读取下层窗口在浮窗区域内的真实像素，不通过临时隐藏浮窗来采样，不启用屏幕捕获排除。部分 GPU 加速、视频或透明窗口不能提供可用像素，此时保持清透材质。
- **Windows 10 2004（Build 19041）及以后 / Windows 11**：使用桌面采样与系统捕获排除接口避免把浮窗自身重复折射；这些浮窗可能不出现在录屏或屏幕共享中。需要录屏、共享时请选择「轻量」或「关闭」。

背景像素只在内存中处理，不保存截图、不上传。早期 Win10 兼容模式会暂存受大小限制的下层窗口画面，再取出浮窗所需区域；同一窗口内的按钮共用背景，减少重复采样。低配置电脑也可选择不采样背景的「轻量」。Win7 版提供清透材质和水滴形变动效，不提供真实桌面折射。主控制界面与计时文字保持清晰的实体表面，六个功能按钮之间保留透明间隔。

「折射度」控制背景弯曲强度，仅在水滴模式生效；「透明度」越高材质越清透；「边缘高光」控制水滴边缘的明亮程度。WPF 版停止调整约半秒后自动保存，可用「预览玻璃」查看展开的灵动岛；关闭玻璃后参数保留并暂时禁用，重新开启即可继续使用。悬浮球、灵动岛与收起的小水滴使用同一组参数，文字衬底不随材质透明度变淡。

两版支持自选安装目录。Win10/11 版按需处理只读文件，区分文件占用、权限拒绝和回滚失败。安装和卸载在权限拒绝时支持用户选择管理员重试。`dist/FreeIsland-Uninstall-1.0.8.exe` 是独立卸载工具，可读取已有安装记录并显示确认窗口，无需先覆盖旧程序。

“访问被拒绝”仍可能由具体文件权限或系统保护造成；本版不会修改文件 ACL 或关闭安全软件。

悬浮球菜单已移除大圆形底板，保留六个功能按钮和展开动画。无计时任务时，灵动岛收起为跟随材质的小点；在「设置」中可调整空闲小点大小滑杆（0%–100%，对应 3–20 像素，默认 20% 约 6 像素）、有任务时的缩略球直径（40–160 物理像素）及展开大小（75%–150%），点击「应用大小」保存。收起点仍可点击和拖动，电脑模式保留至少 24 × 24、教室模式保留至少 44 × 44 逻辑像素的透明交互区域；悬浮球靠边后的箭头保持原样。

液态玻璃可随时关闭。轻量使用清透表面、细边缘和局部文字衬底，不采样背景；收起的小水滴不循环闪烁或呼吸。Win7 的第三档名称为「水滴动效」，只在交互时显示柔和形变。

覆盖安装会请求旧程序正常退出，暂存并校验新文件后替换；文件短暂占用时重试，替换失败则回滚。升级保留设置、日程以及已有的自启动和桌面快捷方式选择。两种版本分别升级各自的安装目录。
Win7 原生版修正了父窗口重画覆盖原生控件的问题，并停止静止页面持续刷新。验证范围及未完成项目见 [验证记录](VERIFICATION.md)。

## 日常使用

- **使用场景**：默认采用「教室触屏」，放大文字、计时显示和操作目标，方便远距离查看及触摸；可在窗口顶部切换到更紧凑的「电脑桌面」。选择会保存在本机，切换场景不改变计时和日程数据。
- **悬浮球**：拖动调整位置；点击展开围绕球体排列的环形功能菜单，进入正计时、倒计时、日程、关机和设置。
- **靠边隐藏**：在设置中开启后，将球拖到屏幕边缘，稍候自动收起，只保留很小的箭头；触摸、点击或将鼠标移入箭头即可唤回。课堂场景的小箭头保留至少 44 × 44 逻辑像素的透明触控区域，方便手指触达。
- **找回悬浮球**：系统托盘右键选择「找回悬浮球」，或使用 `Ctrl + Alt + 空格` 呼出环形菜单。快捷键被其他应用占用时，可使用托盘入口。
- **灵动岛**：在设置中选择顶部、左侧或右侧；展开的灵动岛和收起的小点都可以拖动，松手后吸附到最近的上、左或右边缘，并记住显示器和沿边位置。操作计时器和收到提醒时按需出现，数秒后自动收起；有计时任务时显示时间缩略球和任务数量，点击同时展开当前计时卡片。也可从托盘选择「显示当前计时」。
- **正计时**：开始、暂停、继续与归零。
- **倒计时**：教室模式使用时、分、秒滑块与加减微调，选择快捷时长后仍需点击开始；电脑模式保留输入时长。支持暂停、继续、取消，到时显示灵动岛提醒。
- **全屏展示**：将正计时或倒计时放大到全屏展示窗口，方便全班从远处查看。
- **日程提醒**：创建指定日期时间的一次性提醒，或每天重复提醒。教室模式提供触屏日期与时分选择；日程保存在本机。
- **预约关机**：选择未来的关机时间，最后 10 秒显示灵动岛预警；此前不占计时缩略球，可以在控制中心、托盘菜单或关机提醒中取消。
- **后台运行**：关闭控制中心后应用继续在托盘运行；从托盘菜单选择「退出浮岛」才会完整退出。

两种场景共用一致的矢量图标和操作语言。展开、收起与状态变化使用短动画提供反馈。

## 数据与边界

本地设置和日程位于 `%APPDATA%\FreeIsland`，基础功能无需账户或网络连接；开启自动更新时会连接 GitHub。卸载时默认保留这些数据，只有勾选「同时删除本地设置和日程」才会移除。

电脑休眠、关闭或浮岛退出时，不能实时显示提醒。再次运行或唤醒后会处理已到期的提醒。单次关机预约只在本次运行中生效，不会在重启应用后恢复；循环计划保存所选星期和时间，重启后重新计算下一次未来执行时间；如果休眠等原因错过关机时间，计划会取消，避免唤醒后突然关机。Windows 上其他程序可能阻止正常关机，浮岛不会强制终止它们。

窗口采用系统 DPI 感知。在不同缩放比例的多显示器上，Windows 可能对窗口进行缩放；此版本未承诺所有混合 DPI 布局都有同等清晰度。

目前没有实体 Windows 10 1507 电脑或教学触摸大屏可供验证。开发验证覆盖 Windows 本机渲染与安全模式中的交互，不代表已经验证具体旧系统、显卡、大屏型号、触摸驱动或教室观看距离；没有执行真实的 Windows 关机测试。

## 卸载

在 Windows「设置 → 应用 → 已安装的应用」中找到「浮岛 · Free Island」并卸载，也可以运行安装目录内的 `FreeIsland.Uninstall.exe`。卸载器请求应用正常退出，只删除已知安装文件、属于该安装的快捷方式和注册表项。它不会强制结束其他程序。卸载器会临时复制到系统临时目录完成卸载，该临时文件可随 Windows 临时文件清理删除。

## 从源代码构建 WPF 版

项目使用原生 WPF / WinForms 和 C# 5，运行时没有 Electron、Node.js 或额外 NuGet 依赖。在 Windows PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

构建脚本调用 Windows .NET Framework 自带的 `csc.exe`，严格引用 .NET Framework 4.6 参考程序集。优先使用已安装的 4.6 Developer Pack；若未安装，`tools/Get-Net46References.ps1` 会在首次构建时从 NuGet 下载固定版本 1.0.3 的微软官方 `Microsoft.NETFramework.ReferenceAssemblies.net46` 包，校验 SHA-256 后缓存到 `artifacts/`。这些文件仅供编译使用，不安装运行环境，也不随应用作为运行依赖分发。首次获取参考文件需要网络，已有缓存后可复用。

构建生成图标、应用、卸载器、安装器、免安装 ZIP 与校验清单，并运行核心行为测试。测试使用模拟时间和注入的关机动作，不会执行实际关机或修改开机启动。

目录说明：

| 路径 | 内容 |

安装包还支持仅提取并校验内嵌文件的验证模式，不安装、不启动应用、不创建快捷方式、不写入注册表：

```powershell
.\dist\FreeIsland-Setup-1.0.8.exe --verify-payload "D:\free island\artifacts\payload-check"
```

UI 调试可使用应用的安全模式（演示关机，不会真正关闭 Windows）：

```powershell
.\dist\FreeIsland\FreeIsland.exe --test-ui
```

`--silent` 表示静默启动。安全模式用于开发验证；正常使用请通过开始菜单、桌面快捷方式或直接运行应用。

布局与按钮集成验证：运行 `FreeIsland.exe --smoke-test`，会在隔离的测试数据中捕获课堂大屏与电脑桌面两种场景以及全屏展示窗口，并检查六个页面、计时按钮、日程添加、模拟关机预约/取消、三个方向的灵动岛收起点及四条边的悬浮球收起尺寸。结果输出到程序旁的 `smoke-artifacts`，完成后自动退出。该检查不安装应用、不更改正式用户数据，也不执行真实关机。
